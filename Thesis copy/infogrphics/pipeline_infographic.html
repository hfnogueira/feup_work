Step 2 · Feature Engineering
Phenological Window Features + Discretisation
features creation_v2.R
For each year (y1) uses the DOY of each phenological stage as anchor. Computes climate aggregates in centred (c), before (b) and after (a) windows in both the current (y1) and prior (y0) year. All 59 features are then frequency-discretised (equal-frequency bins) for CarenR input.
Inputs
dataPrep_meteo_*.csv dataPrep_production_*.csv

Window notation
_c{n} — centred ±n/2 days _b{n} — n days before stage _a{n} — n days after stage _y1 current year · _y0 prior year

Step 3 · Rule Discovery
Distribution Rules via CarenR
carenR__application.R  ·  caren_integrated.R (CarenR package)
CarenR wraps a Java-based rule engine. In Distribution Rules mode (Dist=TRUE, POI="Wine_mhl") it discovers subgroups of years (defined by antecedents on climate features) whose wine production distribution is statistically different from the global one (KS test). Rules include mean, stdev, support and p-value.
Inputs
dataPrep_dis_rule_dataset_rdd.csv dataPrep_dis_rule_dataset_rvv.csv

Key Parameters
min.sup — minimum support min.conf — minimum confidence Alpha — KS test significance POI = "Wine_mhl"
What each rule contains
Antecedent — climate subgroup conditions Ant_sup — fraction of years covered pvalue — KS test (distribution shift) Mean · Stdev of Wine_mhl in subgroup Dist — full value distribution string
Outputs
RulesTemp2.csv
Distribution rules (csv) RulesTemp.prm
Prediction model file

Visualisation
plot.drs() — density plots per rule pp.dr() — console pretty-print
